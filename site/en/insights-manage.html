Editorial guide

Write, review, and share.

A shared editorial space for research and sales. Edit the source in GitHub, review the content, and publish it to the journal.

Editing requires write access to this GitHub repository. This page is a guide, not a separate CMS or login service. The repository owner manages research and sales access.

Create an articleAll source files

  1. Write a draft

    Edit an existing article or create a source file. Add a title, summary, headings and paragraphs using verified information and licensed images.

  2. Review the content

    Keep published: false while drafting. After review, set it to true and commit the change, or open a Pull Request for review.

  3. Check publication

    Changes on the default branch rebuild the list, articles and RSS. After a successful GitHub Actions deployment, check the result on desktop and mobile.

Authoring rules

  • Match the filename and slug using lowercase letters, numbers and hyphens: network-operations.json / network-operations.
  • Choose isolate, accelerate or connect for category.
  • Use translations.ko for Korean and translations.en for English. Omit a language if a translation is not available.
  • Add date, updated and author only when the real publication date, revision date and author are known.
  • Upload licensed images under site/assets and set image to the matching path. Check image rights and credit.
  • Set published to false to remove an article from public pages and RSS while retaining its source.
