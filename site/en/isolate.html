Inside the connection

Tunnels define paths.
VRFs define routing boundaries.

SPN links tunnels between device modules and gateways to separate routing spaces. It uses the transport network while defining destinations and communication boundaries for each device.

Common questions

Questions to resolve
before deployment.

Does every endpoint need a security agent?+

SPN creates separated paths through device modules (PGW) and gateways (SGW). Cameras and sensors that are difficult to equip with endpoint software can be considered; module and connection requirements depend on the equipment.

How does SPN relate to VPNs and VLANs?+

SPN combines device-specific tunnels with separate VRFs. Existing VPN and VLAN configurations are considered when deciding where and how to define communication boundaries.

Can existing network infrastructure be used?+

Tunnels run over the existing transport network. Equipment, topology and operational change constraints determine placement and transition planning.

Which types of traffic are considered?+

The primary areas are monitoring, management, data collection and remote access. These are scoped separately from real-time control loops, with deployment boundaries based on device communication and operating requirements.
