글 관리 안내

인사이트를 쓰고, 함께 관리합니다.

연구소와 영업에서 기술과 현장의 이야기를 이어가는 공간입니다. 원고는 GitHub에서 수정하고 검토한 뒤 게시합니다.

편집에는 해당 GitHub 저장소의 쓰기 권한이 필요합니다. 이 페이지는 별도 CMS나 로그인 서비스가 아니며, 연구소·영업의 접근 권한은 저장소 소유자가 관리합니다.

새 글 작성전체 원고 폴더

  1. 원고 작성

    기존 글을 수정하거나 새 원고를 만드세요. 제목·요약·소제목·문단을 입력하고, 실제로 확인한 내용과 사용 권한이 있는 사진을 담습니다.

  2. 내용 검토

    초안은 published: false로 보관합니다. 담당자의 검토를 마친 뒤 true로 바꾸고 커밋하거나 Pull Request로 검토를 요청하세요.

  3. 게시 확인

    기본 브랜치에 반영하면 목록·글·RSS가 함께 생성됩니다. GitHub Actions의 배포가 성공한 뒤 PC와 모바일에서 내용을 확인하세요.

작성 규칙

  • 파일명과 slug는 같은 영문 소문자·숫자·하이픈으로 만듭니다. 예: network-operations.json / network-operations.
  • category는 isolate, accelerate, connect 중에서 선택합니다.
  • translations.ko에 한국어, translations.en에 영어 원고를 넣습니다. 번역이 없으면 해당 언어는 생략합니다.
  • date·updated·author는 확인된 실제 게시일·수정일·작성자가 있을 때만 입력합니다. 기존 글에는 임의 날짜를 붙이지 않습니다.
  • 새 이미지는 site/assets 아래에 올리고 image에 해당 경로를 입력합니다. 사진 출처와 사용 권한을 확인하세요.
  • 글을 내릴 때는 published를 false로 변경합니다. 원고는 보관되고 공개 목록·글·RSS에서 제외됩니다.
상세 운영 안내

읽을 수 있는 본문

개별 글은 자바스크립트 없이도 읽히는 HTML로 게시되며, 전체 본문 RSS와 글의 구조화 데이터를 제공합니다. 현재 검토 사이트의 noindex 설정은 유지됩니다. 검색엔진이나 AI 서비스의 수집·노출을 보장하지 않으며, 정식 공개 때 색인 정책을 별도로 정해야 합니다.
